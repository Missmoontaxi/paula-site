# paulamcmahon.com

My personal site showcasing work, life, and how to get in touch.

🌐 **Live:** [paulamcmahon.com](https://paulamcmahon.com)

---

## Stack

- **Framework:** Next.js + TypeScript
- **Styling:** Tailwind CSS
- **Hosting:** Vercel
- **Domain & DNS:** Managed via Vercel

## Notes from building it

- **Why code it.** No-code would have been faster. But I wanted to be inside the same stack most founders are in.
- **Claude Code as the pair.** Most of this was built with Claude Code, not generating the whole thing, but explaining what each piece does so I can debug it later.
- **Vercel DNS was the gotcha.** Connecting paulamcmahon.com with the right redirects took longer than building any of the actual pages.
- **The site evolves with my work.** No marketing-team-approved redesigns, edirs ship when I have something to say.
